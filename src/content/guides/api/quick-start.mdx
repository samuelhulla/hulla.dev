Build a small API that creates a task from a title. You'll write the handler and call it from a TypeScript script, then see the new task printed in your terminal.

Everything runs in that script for now, so there's no HTTP server to set up.

## Prepare the project

First, describe the route in a [contract](/docs/api/core/contracts). Both the client and server will import this file so they agree on what to send and what to return.

```ts filename="src/api/contract.ts"
import { defineContract, request, response, route } from '@hulla/api'
import { z } from 'zod'

const newTask = z.object({
  title: z.string().min(1),
})

export const task = z.object({
  id: z.string(),
  title: z.string(),
  completed: z.boolean(),
})

export const contract = defineContract({
  basePath: '/api',
  routes: {
    createTask: route.post('/tasks', {
      body: request.json(newTask),
      responses: {
        201: response.json(task),
      },
    }),
  },
})
```

`z.string().min(1)` rejects an empty title. The name `createTask` will also be the name of the client method, so keep it handy for step 3.

Now write the handler. It receives a validated `body`, gives the task an ID, and returns it with status `201` (Created).

```ts filename="src/api/implementation.ts"
import { defineServer } from '@hulla/api/server'
import { contract } from './contract'

export const implementation = defineServer(contract).implement({
  createTask: ({ body, response }) =>
    response(201, {
      id: crypto.randomUUID(),
      title: body.title,
      completed: false,
    }),
})
```

There is one route to implement, so we need one handler. If you add another route to the contract, TypeScript will ask you to implement that one too.

Create a client from the contract and connect it to the implementation with `inProcessTransport()`. This lets the script call your handler directly, so there is no web server to start.

```ts filename="src/api/example.ts"
import { createClient } from '@hulla/api/client'
import { inProcessTransport } from '@hulla/api/in-process'
import { contract } from './contract'
import { implementation } from './implementation'

const api = createClient(contract, {
  transport: inProcessTransport(implementation),
})

const result = await api.createTask({
  body: { title: 'Write the quick start' },
})

console.log(result.body)
```

Run it from the project root:

```sh
bun src/api/example.ts
```

The call prints a task shaped like this:

```ts
{
  id: 'generated-id',
  title: 'Write the quick start',
  completed: false,
}
```

Change the title and run it again. The response should contain your new text and a generated ID.

> [!NOTE] This example does not save tasks
> The handler returns a new task on each call. To keep tasks after the script exits, add a database or write them to a file.

Try an empty title next. Validation should reject the call before your handler creates a task.

## Use it in an app

You now have a working API call. Where you take it next depends on your app:

- Use [HTTP calls with Fetch](/docs/api/transports/fetch) to call the API from a browser or another service.
- Choose a [server adapter](/docs/api/servers) to serve the API with Express, Fastify, Hono, or another framework.
- Read [Organizing server code](/docs/api/core/server-composition) when the contract grows beyond one module.
- Read [Calling the API](/docs/api/core/clients) to handle responses and share client setup.
