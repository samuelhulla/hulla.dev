---
title: Variants
description: Map a finite set of component choices to class strings and let TypeScript infer the prop values.
usefulFor:
  - Your component has named sizes, tones, or states.
  - You want component props to stay in sync with their class map.
  - You need to choose which variant props are required or have defaults.
---

When a component offers a fixed set of visual choices, a `vn` map keeps the choice and its classes together. The returned function accepts only keys from that map, and its `.infer` property exposes those keys as a TypeScript union.

## Define and type a choice

Create the map near the component that consumes it. This `tone` map belongs in a component module; it does not create CSS rules, it only returns the selected class string.

```tsx filename="src/components/Notice.tsx"
import type { ReactNode } from 'react'
import { cn, vn } from '../lib/style'

const $tone = vn({
  info: 'border-blue-300 bg-blue-50 text-blue-950',
  warning: 'border-amber-300 bg-amber-50 text-amber-950',
})

type NoticeProps = {
  tone: typeof $tone.infer
  children: ReactNode
}

export function Notice({ tone, children }: NoticeProps) {
  return (
    <aside className={cn('rounded border p-4', $tone(tone))}>{children}</aside>
  )
}
```

`$tone.infer` is the union `"info" | "warning"`. A caller can pass `<Notice tone="warning">Check the date.</Notice>`, and TypeScript reports an error for a value such as `tone="success"` because that key is not in the map.

Use `typeof $tone.infer` only in a type position. `.infer` is `undefined` at runtime; call `$tone('warning')` to get the class string. Keep the inferred union on the component prop, then pass the selected key to the variant function. An optional prop has type `typeof $tone.infer | undefined`, which cannot be passed to `$tone` until you provide a default or narrow away `undefined`.

## Choose required and defaulted props

`vn` does not select a default on its own. Make a prop optional and set its JavaScript default in the component when omission should select a style; leave the prop required when callers must choose explicitly.

```tsx
const $size = vn({ compact: 'text-sm', regular: 'text-base' })

type LabelProps = { size?: typeof $size.infer }

function Label({ size = 'regular' }: LabelProps) {
  return <span className={$size(size)}>Ready</span>
}
```

The parameter default makes `<Label />` render with `text-base`. A required prop instead forces the caller to choose a key before the component can render. Keep each map flat and focused; if multiple choices need to be combined, use separate maps and join their results with `cn` in [Composition](/docs/style/composition).

`vn()` passes the selected map value through the `cn` function created by the same `style()` instance. This means custom serialization and composition apply to variant output too. For exact type and runtime signatures, see the [API reference](/docs/style/reference).
