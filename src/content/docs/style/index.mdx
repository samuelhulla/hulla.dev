`@hulla/style` combines class names and gives components named choices such as `small` or `large`. It works with your existing CSS and framework.

Using a coding agent? [Install the hulla-style skill](/guides/style/quick-start#optional-agent-skill) for package-specific guidance.

## Combine classes

Create the helpers once, then pass classes and conditions to `cn()`:

```ts
import { style } from '@hulla/style'

const { cn } = style()
const isActive = true

cn('button', { active: isActive }) // 'button active'
```

Use [`vn()`](/docs/style/variants) to map names to classes. For Tailwind conflict resolution, [configure a custom composer](/docs/style/custom-merging).
