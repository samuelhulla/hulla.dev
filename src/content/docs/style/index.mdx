`@hulla/style` turns conditional classes and named variants into one class string. Your application chooses the CSS system and framework.

<DocsConceptFlow
  label="Class composition"
  steps={[

      title: 'Combine with cn',

    },

/>

It does not generate CSS or markup. The default composer removes repeated tokens; configure a Tailwind-aware composer to resolve utility conflicts.
