`@hulla/args` turns command-line input into typed values. Declare the options and commands your CLI accepts, then parse the arguments with Zod validation.

Your code decides what to do with the result, including printing help and reporting errors.

Using a coding agent? [Install the hulla-args skill](/guides/args/quick-start#optional-agent-skill) for package-specific guidance.
