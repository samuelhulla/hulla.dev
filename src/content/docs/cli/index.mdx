The `hulla` CLI copies UI components into your application. You can read, edit, and commit those files like the rest of your code. Run `hulla doctor` to inspect declared package integrations and configuration across your workspaces.

The CLI requires Bun. Your installed components build with your app and don't need the CLI at runtime.

Using a coding agent? [Choose and install package skills](/docs/cli/agent-skills) for the packages your application uses.
