The `hulla` CLI initializes project configuration and copies UI component source files into your application. Use it when you want to own and edit the components in your repository; the installed code does not need the CLI or registry at runtime.

The CLI currently requires Bun. Its `api` commands target an older `@hulla/api` generation interface and are not compatible with the current `@hulla/api` 2.0 API. For new API work, use the [current API quick start](/docs/api/quick-start).
